# 雨林食物鏈探險隊

小四科學：11 種動物＋2 類植物，自由探索、靠近食性卡、圖鑑及食物鏈工作台。

11 種動物均使用 Tripo H3.1 完整 GLB 模型及內嵌彩色與 PBR 材質，按要求不加骨架。動物沿場景路線自行活動；模型沒有四肢、拍翼或蛇身骨架動畫。

已移除樹懶、眼鏡鴞、無尾刺豚鼠及虎貓，並同步清理圖鑑、食物鏈與探索目標。舊存檔保留有效進度。

GitHub Pages：main 分支 /docs。動物觀察室：materials.html。驗證：node --test tests/*.test.mjs。

模型幾何保留 Tripo 生成結果，網頁版本壓縮內嵌材質尺寸以控制載入量；來源見 docs/assets/models/generation-status.json。Three.js MIT 授權見 docs/vendor/THREE-LICENSE.txt。完整 WebGL 光影及 iPad 效能待實機驗證。

操作更新：WASD／方向鍵按畫面方向移動，放開即停；觸控搖桿設有中央防誤觸區。輕點可行走地面會顯示金色目的地，按空白鍵、Esc 或「停止」取消；方向鍵或搖桿立即接手。拖曳視角、右鍵與雙指操作不會觸發點地面前往。遇到障礙會停止並提示，並非自動尋路。

移動按經過時間計算（單幀最多 0.25 秒），碰撞以短步距檢查；近看模型後移動會恢復原本探索視角。操作回歸測試包含 60／20／4 FPS 位移一致、樹幹及河流碰撞、橋樑可通行、停止與失焦、搖桿及拖曳誤判。


## 海洋食物鏈探險隊

入口：`docs/maps/?map=ocean`。2 種海草、15 種海洋動物，共17個 Higgsfield / Tripo 彩色無骨架模型。動物以整體位移及轉向活動。包含自動觀察卡、圖鑑、食物鏈工作台及獨立瀏覽器儲存。

驗證：`node --test tests/*.test.mjs`。瀏覽器相容模式已檢查；iPad 實機及完整 WebGL 光影尚未驗證。


## 沙漠與草原地圖

入口：`docs/maps/?map=desert`、`docs/maps/?map=savanna`。海洋及沙漠各包含2種植物和15種動物；草原包含2種植物和14種動物。各自採用Higgsfield／Tripo彩色無骨架GLB；全三圖共50種。沙漠包含綠洲、沙丘與乾旱地帶生物，草原包含草地、疏林與非洲草原生物。

地圖可從頂部切換，僅載入所選地圖模型，學習進度按地圖分開儲存在目前瀏覽器。教學簡化及食性來源見各圖「老師筆記」。

驗證：25項自動檢查通過，包含三圖名單、模型內嵌材質、無骨架、食物鏈方向與獨立存檔。瀏覽器使用相容顯示模式驗收；完整WebGL與iPad實機仍待驗證。


2026-10-29 草原名單更新：移除非洲象及白犀牛，加入斑鬣狗（Crocuta crocuta），共2種植物＋14種動物。斑鬣狗可捕獵及取食腐肉，食物鏈以草→斑馬／角馬／瞪羚→斑鬣狗為例；不把與獅子的競爭誤作常規捕食箭頭。舊存檔保留其餘有效觀察卡與食物鏈，自動移除已刪物種。
